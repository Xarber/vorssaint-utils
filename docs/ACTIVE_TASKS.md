## Repository context and integration

Vorssaint is an Apple Silicon utility for macOS 14 and later. Its AppKit and SwiftUI app uses `App/AppDelegate.swift`, `App/FeatureRuntime.swift` and `Core/FeatureCatalog.swift` to manage optional features. Settings and localization use `Core/Defaults.swift`, `Core/SettingsBackupSupport.swift`, localized string catalogs and localized permission messages in `Resources`. `build.sh` assembles the app and compiles the standalone test harness. `Package.swift` primarily supports editor indexing. The existing CI checks Swift 6.0.3 on macOS 15 and builds on macOS 26. Keep that compatibility floor and follow the Swift isolation and concurrency guidance in new modules within that compiler baseline.

Publication, upstream PRs, and a branch or release migration are outside this planning pass. The existing app is GPL-3.0-or-later under `LICENSE` and `CONTRIBUTING.md`.
